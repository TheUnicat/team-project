## User Stories
- As a player, I want to play minesweeper in $1^{st}$ person point of view so I can have a more immersive experience
while playing minesweeper.
- As a player, I want the game to have clear instructions so I can easily understand the game controls and the
expectation of the game.
- As a player I want my game progress to be saved so I can continue playing another time after I quit the game.
